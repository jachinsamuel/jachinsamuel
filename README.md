### Featured Engineering Systems

#### 01 / [FoodyBuddy](https://foodybuddy.shop) &nbsp;·&nbsp; `Production Campus Dining & Logistics Platform`
> High-concurrency campus ordering ecosystem built for peak mealtime traffic spikes. Engineered with real-time order state synchronization, verified Razorpay payment webhook reconciliation, automated Twilio merchant SMS notifications, and merchant operations analytics.
>
> **Architecture & Stack**: `React` · `Flask` · `PostgreSQL` · `Razorpay` · `Twilio` &nbsp;·&nbsp; **Direct Deployment**: [foodybuddy.shop ↗](https://foodybuddy.shop)

#### 02 / [Ace](https://github.com/jachinsamuel/Ace) &nbsp;·&nbsp; `Terminal AI Git Copilot (Published on PyPI)`
> Intelligent command-line copilot that parses natural language developer intent into verified Git commands, drafts contextual commit messages, and provides an interactive terminal UI workflow. Packaged and distributed globally via PyPI.
>
> **Architecture & Stack**: `Python` · `CLI` · `TUI` · `Ollama` &nbsp;·&nbsp; **Distribution & Code**: [GitHub Repository ↗](https://github.com/jachinsamuel/Ace) · [PyPI Package ↗](https://pypi.org/project/ace-cli/)

#### 03 / [Nexus](https://github.com/jachinsamuel/RAG-Nexus) &nbsp;·&nbsp; `Enterprise Offline-First Local RAG Engine`
> Self-contained local knowledge retrieval platform featuring a spatial glassmorphic UI, multi-provider local LLM streaming via Ollama, and vector similarity indexing operating with absolute zero cloud egress.
>
> **Architecture & Stack**: `Python` · `FastAPI` · `SQLite` · `Ollama` · `Vector Search` &nbsp;·&nbsp; **Artifacts**: [GitHub Repository ↗](https://github.com/jachinsamuel/RAG-Nexus)

#### 04 / [MaternCare](https://materncare.vercel.app/) &nbsp;·&nbsp; `Clinical Decision Support & Telemetry Dashboard`
> Healthcare decision support platform utilizing supervised machine learning models to assess multi-parameter maternal vital signs and surface real-time clinical risk classification through responsive telemetry dashboards.
>
> **Architecture & Stack**: `React` · `Flask` · `Scikit-Learn` · `Recharts` &nbsp;·&nbsp; **Direct Deployment**: [materncare.vercel.app ↗](https://materncare.vercel.app/)

#### 05 / [VoiceCalc](https://voicecalc-5io4.onrender.com) &nbsp;·&nbsp; `Real-Time Speech-to-Math Computation Engine`
> Continuous speech parsing engine converting conversational spoken arithmetic into parsed mathematical ASTs with real-time voice synthesis feedback and sub-second evaluation.
>
> **Architecture & Stack**: `Flask` · `Web Speech API` · `JavaScript` · `CSS3` &nbsp;·&nbsp; **Direct Deployment**: [voicecalc-5io4.onrender.com ↗](https://voicecalc-5io4.onrender.com)
